# КР №3: пять интерактивных функций

Дата реализации: 12 ноября 2026 года.

Выбранные функции реализованы в существующем сайте «Лапки» на Bootstrap. Используется обычный JavaScript: без React, npm, сборщика и серверной базы данных.

## Где нажимать

| Функция | Где находится |
| --- | --- |
| Избранное | Сердечко в карточках и пункт «Избранное» в меню |
| Калькулятор и сравнение | Каталог → «Калькулятор и сравнение»; отметки «В сравнение» в карточках |
| Тёмная тема | Переключатель в шапке каждой страницы |
| Всплывающий помощник | Кнопка «Нужна помощь?» слева внизу |
| Поиск | Поле поиска в шапке, результаты на search.html |

## Как устроен код

Общий массив lapkiPlaces в js/data.js содержит id, название, цену и условия трёх предложений. Добавленные функции используют эти данные. Статические описания в HTML сохранены для читаемости; при изменении тарифов следует согласовать их с массивом.

Интерфейс работает по событиям: click, input и change вызывают обработчики. Обработчик меняет данные и соответствующие узлы DOM. Например, при выборе сердечка меняется массив id, затем надпись кнопки, её aria-pressed и счётчик. Для такого небольшого сайта отдельный JavaScript-фреймворк не нужен.

### Избранное

Файлы: js/favorites.js, js/data.js, favorites.html.

В localStorage под ключом lapki-favorites хранится JSON-массив id. При загрузке остаются только существующие, неповторяющиеся значения. Нажатие на сердечко добавляет или удаляет id, сохраняет массив и обновляет интерфейс. На странице избранного из этого массива строятся карточки; пустое состояние и очистка списка предусмотрены.

Выбор для сравнения хранится отдельно — lapki-comparison. Поэтому удаление из избранного не удаляет предложение из сравнения. Если хранилище недоступно, функции продолжают работать на текущей странице.

### Калькулятор и сравнение

Файлы: js/tools.js, js/data.js, раздел calculator в catalog.html.

Общая функция lapkiCalculate используется и калькулятором, и таблицей сравнения. Это предотвращает расхождение формул.

Расчёт:
- размещение = цена суток × количество суток;
- груминг = 900 ₽ однократно, если выбран;
- индивидуальный уход = 350 ₽ × количество суток, если выбран;
- дополнительные прогулки = 200 ₽ × число прогулок в день × количество суток, только для собак.

В тариф собак уже включены две прогулки; поле задаёт дополнительные. Допускаются целые значения: 1–365 суток и 0–3 дополнительных прогулки. При неправильном вводе вместо итогов показывается прочерк и сообщение, а не NaN или отрицательная стоимость.

Для примера: «Простор», 3 суток, груминг, уход и 2 дополнительные прогулки в день — 3600 + 900 + 1050 + 1200 = 6750 ₽. Для кошек дополнительные прогулки не начисляются.

При выборе двух или трёх передержек строится таблица: питомец, цена, размещение, прогулки, кормление, расходы за период и итог. Период и услуги общие, а вид животного и доступность прогулок учитываются для каждого предложения. Отметки синхронизируются с карточками.

### Тёмная тема с анимацией

Файлы: js/theme.js и css/custom.css.

Скрипт темы подключён в head до CSS. Он читает lapki-theme и задаёт атрибут data-bs-theme у html до появления содержимого. Bootstrap использует этот атрибут для своих компонентов, а CSS-переменные проекта меняют фон шапки, секций и собственных элементов.

При нажатии кнопки тема сохраняется в localStorage. Цвета плавно меняются за 0,3 секунды, ползунок сдвигается. Настройка prefers-reduced-motion отключает анимацию для пользователей, которым нужно уменьшение движения.

### Всплывающий помощник

Файлы: js/widget.js, общий блок helpPanel во всех HTML-страницах, стили help-panel.

По уточнению пользователя реализовано приветствие «Здравствуйте! Нужна помощь с выбором передержки?», а не переписка с оператором. Через четыре секунды первой страницы появляется подсказка слева внизу. Она содержит ссылки на каталог, калькулятор и контакты.

Крестик и Escape закрывают подсказку. Кнопка «Нужна помощь?» открывает её повторно. sessionStorage хранит, что приветствие уже показано, поэтому при переходах оно не всплывает снова автоматически. Виджет не блокирует страницу и не является модальным окном.

### Поиск по сайту

Файлы: js/search.js и search.html; форма в шапке всех страниц.

Форма передаёт запрос в параметре q. fetch загружает HTML главной, каталога, условий, контактов и избранного. DOMParser выделяет разделы main и их заголовки. Скрипт сравнивает текст со всеми словами запроса без учёта регистра и различия е/ё.

Результаты ведут к конкретным разделам; для предложений животных формируется параметр place, поэтому поиск «Простор» открывает вкладку собак. Совпадения в заголовке получают приоритет. Тексты обновляются вместе со страницами, отдельный ручной поисковый индекс не требуется.

Запрос и тексты результатов выводятся через value/textContent, без вставки пользовательского HTML. Есть состояния загрузки, отсутствия совпадений и частичной недоступности страниц.

## Что проверено

- Синтаксис всех JavaScript-файлов, локальные ссылки, id, SVG и одинаковый порядок меню шести страниц.
- Правильные суммы для всех трёх предложений, однократный груминг, доплаты за сутки и прогулки только для собак.
- Нулевые, отрицательные, дробные и слишком большие значения периода; дробные прогулки.
- Удаление повторных/неизвестных id при чтении хранилища и работа при ошибке доступа.
- Сохранение темы, избранного и сравнения после перезагрузки и переходов.
- Удаление отдельного избранного и очистка списка, пустое состояние.
- Поиск «Простор», переход на вкладку собак, поиск без совпадений.
- Показ/закрытие помощника и мобильное меню.
- Ширина 375 и 1440 px для всех шести страниц: горизонтального переполнения документа нет. Таблица сравнения прокручивается внутри table-responsive.
- Во время проверки в консоли браузера не было ошибок JavaScript.

Заказы, бронирование и отдельные модальные формы не добавлялись. Lighthouse не запускался; этот документ описывает пять согласованных функций, а не подтверждает все возможные требования методички КР №3.
