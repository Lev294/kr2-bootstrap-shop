По новому указанию пользователя «Лапки» позиционируются как онлайн-агрегатор передержек без собственного физического места. Адрес удалён со всех страниц и из README. Контакты относятся к поддержке сервиса; номер из локальной правки пользователя сохранён. Уход и размещение в текстах отнесены к исполнителям. Новые ссылки используют place, старые room и якоря сохранены для совместимости. По просьбе пользователя дополнительные проверки этой правки не выполнялись; результаты выше относятся к предыдущим версиям.
