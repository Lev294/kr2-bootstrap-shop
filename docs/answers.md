Проект: «Лапки» — гостиница для домашних животных. Автор: Демидовс Лев Алексейсович.

Здесь собраны все 62 вопроса: 20 для №9, 20 для №10 и 22 для №11. Формы заказа и модальные окна рассматриваются теоретически: пользователь отложил их реализацию. Форма отзыва сохранена, поскольку она не связана с заказом.

## Практическая работа №9

### 1. Что такое CSS-фреймворк?

CSS-фреймворк — библиотека готовых стилей, соглашений и компонентов для построения интерфейса. Она задаёт повторно используемые решения для сетки, типографики, форм и других элементов; в Bootstrap часть компонентов дополнена JavaScript.

### 2. Почему Bootstrap выбран как основной фреймворк в данной работе?

Он предусмотрен методическими указаниями и объединяет адаптивную сетку, компоненты и utility-классы. Для этого проекта достаточно подключить готовые CSS и JS: сборка и отдельный JavaScript-фреймворк не нужны.

### 3. Чем Bootstrap отличается от обычного CSS-файла?

Технически стили Bootstrap тоже распространяются как CSS-файл. Разница в содержимом: это согласованная универсальная библиотека классов, а custom.css содержит небольшие правила конкретного сайта.

### 4. Для чего используется класс container?

Он ограничивает ширину содержимого на разных breakpoints, центрирует блок и добавляет горизонтальные внутренние отступы. В «Лапках» так выровнены навигация и основные разделы.

### 5. Чем container отличается от container-fluid?

У container максимальная ширина меняется ступенчато по breakpoints. container-fluid занимает 100% доступной ширины родителя; в hero он даёт широкий фон, а вложенный container ограничивает содержимое.

### 6. Для чего используется класс row?

row создаёт строку Flexbox-сетки с переносом колонок. Она также участвует в формировании gutters и компенсирует часть отступов колонок отрицательными внешними отступами.

### 7. Почему классы col-* должны находиться внутри row?

Сетка рассчитывается как совместная работа строки и её непосредственных колонок. row задаёт flex-контекст и gutters; без неё col-* может получить ширину, но раскладка и промежутки не будут работать как предусмотрено.

### 8. Сколько колонок используется в Bootstrap-сетке?

Стандартная сетка состоит из 12 долей. Например, две колонки col-6 занимают по 6/12 строки, а три col-4 — по 4/12.

### 9. Что означает класс col-12?

Колонка занимает все 12 долей, то есть ширину строки. Без префикса breakpoint правило действует от самого маленького экрана, пока более подходящий класс его не переопределит.

### 10. Что означает класс col-md-6?

При ширине viewport от 768 CSS-пикселей колонка занимает 6/12 строки, то есть половину. В комбинации col-12 col-md-6 на меньшей ширине остаётся одна карточка в строке.

### 11. Что означает класс col-lg-4?

От 992 CSS-пикселей колонка занимает 4/12 строки, то есть треть. Поэтому сочетание col-12 col-md-6 col-lg-4 даёт один, два и три элемента в строке.

### 12. Для чего используются breakpoints?

Это пороги ширины viewport, на которых media queries меняют правила оформления и раскладки. Bootstrap использует подход mobile first: базовые правила дополняются правилами для большей ширины.

### 13. Для чего используются классы g-*?

Они задают gutters — горизонтальные и вертикальные промежутки между колонками сетки. Значение берётся из шкалы отступов Bootstrap, а не задаёт число колонок.

### 14. Чем g-4 отличается от gx-4 и gy-4?

g-4 меняет оба направления, gx-4 — только горизонтальное, gy-4 — только вертикальное. В стандартной шкале Bootstrap 5.3 уровень 4 равен 1,5rem.

### 15. Для чего используется custom.css?

Для небольших правил конкретного проекта, которых недостаточно получить utility-классами. В «Лапках» это тёплые фоны, размер иллюстраций и перенос длинного текста отзыва.

### 16. Почему собственный CSS подключается после Bootstrap?

В CSS действует каскад. При равных происхождении, важности, слое и специфичности более позднее объявление получает приоритет; сам по себе порядок не побеждает, например, более специфичный селектор.

### 17. Зачем подключать Bootstrap JS Bundle?

Для поведения интерактивных компонентов: collapse, modal, accordion и других. Bundle включает Popper, используемый для позиционирования некоторых компонентов; для одной CSS-сетки JavaScript не требуется.

### 18. Чем Bootstrap отличается от Tailwind CSS?

Bootstrap предлагает готовые визуальные компоненты и utilities. Tailwind строится преимущественно вокруг utility-first-подхода: внешний вид собирают из небольших классов; это иной способ организации CSS, а не отдельный язык браузера.

### 19. Чем Bootstrap отличается от Bulma?

Оба предлагают готовые CSS-компоненты и адаптивную сетку. У Bulma собственные классы columns/column и нет встроенного аналога JavaScript-набора Bootstrap для управления интерактивными компонентами.

### 20. Почему КР №2 выполняется в отдельном репозитории?

Это отдельная учебная реализация с другим технологическим подходом. Раздельные история, исходники и README позволяют независимо проверить Bootstrap-проект и сохранить КР №1.

## Практическая работа №10

### 1. Что такое компонент Bootstrap?

Компонент — повторно используемый элемент интерфейса с определённой HTML-структурой и набором CSS-классов, иногда с JavaScript-поведением. Примеры: card, navbar, accordion.

### 2. Чем компонент отличается от utility-класса?

Компонент организует целый элемент интерфейса и его составные части. Utility-класс обычно задаёт одно небольшое правило или группу связанных правил: например, mb-3 — нижний отступ, text-center — выравнивание текста.

### 3. Для чего используется navbar?

Это компонент навигационной панели: бренд, ссылки и при необходимости сворачиваемое меню. В «Лапках» он одинаков на всех трёх страницах; текущая ссылка отмечена active и aria-current.

### 4. Какие классы нужны для адаптивной навигации Bootstrap?

Основные: navbar, navbar-expand-lg, navbar-toggler, navbar-toggler-icon, collapse navbar-collapse, navbar-nav и nav-link. Кнопка связана с блоком через data-bs-toggle="collapse" и data-bs-target="#mainNavbar"; от lg меню раскрыто постоянно.

### 5. Для чего используется card?

Для визуального объединения связанных данных в карточку. В проекте card используется для номеров, дополнительных услуг и добавленного отзыва.

### 6. Что обычно входит в карточку товара?

Изображение, заголовок, описание, характеристики, цена и действие. Типичные классы: card-img-top, card-body, card-title, card-text; конкретный состав зависит от назначения карточки.

### 7. Для чего используется btn?

Это базовый класс оформления кнопки или ссылки-кнопки. Вариант btn-success, btn-primary или другой задаёт цвет; поведение определяется HTML-элементом: ссылка переходит, button выполняет действие.

### 8. Чем btn-primary отличается от btn-outline-primary?

btn-primary даёт заполненную кнопку основного цвета. btn-outline-primary в обычном состоянии имеет контур и прозрачный фон; это позволяет различать основной и второстепенный акцент.

### 9. Для чего используется badge?

Для короткой метки, счётчика или статуса. В проекте метки показывают вид питомца и занятость номера; значение передано текстом, а не только цветом.

### 10. Для чего используется alert?

Для выделенного сообщения, пояснения или предупреждения. В статических информационных сообщениях проекта используется оформление alert; role="alert" может сообщать о появлении важного сообщения вспомогательным технологиям.

### 11. Для чего используется modal?

Для диалога поверх основной страницы, который временно требует внимания пользователя. Bootstrap управляет подложкой, фокусом и закрытием. В текущей версии «Лапок» modal исключён по указанию пользователя.

### 12. Какие атрибуты нужны для открытия модального окна?

На кнопке обычно задают type="button", data-bs-toggle="modal" и data-bs-target="#dialogId". Окно должно иметь соответствующий id, tabindex="-1" и aria-labelledby, ссылающийся на заголовок; для кнопки закрытия используют data-bs-dismiss="modal".

### 13. Почему для modal нужен Bootstrap JS Bundle?

CSS описывает внешний вид, но сам не обрабатывает переключение состояния, фокус и подложку. Поведение реализует JavaScript-плагин Bootstrap; использовать можно и отдельный плагин, Bundle — удобный готовый вариант.

### 14. Для чего используется form-control?

Для согласованного оформления текстовых input и textarea: размеров, границ и состояний фокуса. Этот класс не заменяет label, name, required и проверку данных.

### 15. Для чего используется form-select?

Для оформления HTML-элемента select с вариантами выбора. Значение и выбранный вариант остаются обычными свойствами нативного select.

### 16. Для чего используется input-group?

Для объединения поля ввода с подписью, префиксом или кнопкой в одну визуальную группу. Например, +7 в input-group-text рядом с телефонным полем; сам префикс не становится частью значения input.

### 17. Для чего используется form-check?

Для оформления checkbox или radio вместе с подписью. Обычно контейнер имеет form-check, поле — form-check-input, а label — form-check-label и соответствующий for.

### 18. Для чего используется accordion?

Для группы раскрывающихся разделов, позволяющей компактно показать подробности. В «Лапках» это FAQ; data-bs-parent связывает панели так, чтобы раскрытие новой закрывало предыдущую.

### 19. Почему собственный CSS должен быть минимальным?

Цель работы — продемонстрировать Bootstrap, а не заново написать его сетку и компоненты. Небольшой custom.css уменьшает дублирование и риск конфликтов с библиотекой.

### 20. Почему КР №2 должна выполняться в отдельном репозитории?

Чтобы проверить отдельную реализацию на CSS-фреймворке и не смешивать её с чистым HTML/CSS-проектом КР №1. В собственном репозитории сохраняются самостоятельная история и описание решений.

## Практическая работа №11

### 1. Почему КР №2 выполняется в отдельном репозитории?

Это самостоятельная контрольная работа с отдельной реализацией, историей коммитов и README. Так преподаватель проверяет применение CSS-фреймворка независимо от КР №1.

### 2. Почему КР №2 не является адаптацией КР №1?

В методичке она определена как новая реализация той же предметной области средствами фреймворка. Меняется основа интерфейса: сетка и компоненты строятся на Bootstrap, а не на CSS-архитектуре первой работы.

### 3. Что такое CSS-фреймворк?

Набор согласованных готовых стилей и соглашений для построения интерфейса. Он предоставляет повторно используемые решения вместо написания каждого элемента с нуля.

### 4. Почему Bootstrap выбран как основной вариант?

Он предусмотрен заданием, документирован и объединяет сетку, готовые компоненты и utilities. Для простого статического сайта его можно подключить без сборщика.

### 5. Какие альтернативные CSS-фреймворки допускаются?

Методичка допускает Tailwind CSS и Bulma по согласованию с преподавателем. При этом требования к структуре, сетке и компонентам должны сохраняться.

### 6. Для чего используется container?

Для центрирования и ограничения ширины содержимого с адаптивными max-width и горизонтальными отступами. Он помогает согласовать положение разделов страницы.

### 7. Для чего используется row?

Для строки Flexbox-сетки, переноса колонок и участия в расчёте gutters. Непосредственно внутри неё размещают колонки.

### 8. Для чего используются col-*?

Для задания доли ширины колонки, в том числе начиная с определённого breakpoint. Например, col-md-6 означает половину строки от ширины 768 CSS-пикселей.

### 9. Что такое 12-колоночная сетка Bootstrap?

Модель, в которой строка делится на 12 условных долей. Это позволяет получать половины, трети и другие пропорции; браузер не создаёт 12 отдельных DOM-элементов автоматически.

### 10. Для чего используются g-*, gx-*, gy-*?

Для промежутков сетки: g-* меняет оба направления, gx-* — горизонтальное, gy-* — вертикальное. Эти классы не задают число колонок.

### 11. Для чего используется navbar?

Для единой навигации по страницам с брендом и ссылками. При необходимости он объединяется с collapse для мобильного меню.

### 12. Почему для мобильного меню нужен Bootstrap JS Bundle?

В текущей разметке кнопка переключает компонент collapse. Его JavaScript изменяет состояние блока и aria-expanded; без плагина data-bs-* остаются лишь атрибутами и не раскрывают меню.

### 13. Для чего используется card?

Для оформления связанной информации в отдельный визуальный блок. Здесь это номер гостиницы, услуга или отзыв.

### 14. Для чего используется badge?

Для компактного текстового статуса или метки. Здесь — «Для кошек», «Свободно» и «Занято».

### 15. Для чего используется alert?

Для визуального выделения сообщений. При динамическом срочном уведомлении role="alert" помогает объявить сообщение, но оформление само по себе не проверяет данные и не отправляет их.

### 16. Для чего используется modal?

Для диалогового взаимодействия поверх текущей страницы с управлением фокусом и подложкой. В текущем проекте этот компонент отложен по указанию пользователя.

### 17. Какие атрибуты нужны для открытия модального окна?

Для декларативного открытия: data-bs-toggle="modal" и data-bs-target="#id" на кнопке и соответствующий id у окна. Для доступности добавляют tabindex и связь с заголовком через aria-labelledby.

### 18. Для чего используются form-control, form-select, input-group, form-check?

Это оформление текстовых полей, select, составного поля с дополнением и checkbox/radio соответственно. Они не заменяют семантическую разметку и валидацию HTML.

### 19. Чем CDN-подключение отличается от локального подключения Bootstrap?

При CDN файлы загружаются с внешнего сервера; при локальном способе лежат в проекте и отдаются вместе с сайтом. CDN проще подключить, локальный способ снижает зависимость от доступности стороннего адреса и позволяет контролировать файлы.

### 20. Какие файлы нужны для локального подключения Bootstrap?

Для этого проекта достаточно bootstrap.min.css и bootstrap.bundle.min.js, например в vendor/bootstrap/css/ и vendor/bootstrap/js/. Bundle уже содержит Popper; для распространения также следует сохранить лицензию библиотеки.

### 21. Почему custom.css должен подключаться после Bootstrap?

Так локальные правила при прочих равных выигрывают по порядку в каскаде. Более высокая специфичность, !important и каскадные слои всё равно могут изменить результат.

### 22. Какие самостоятельные доработки были добавлены в проект?

Тематика гостиницы «Лапки», собственные SVG-иллюстрации, три номера с тарифами, пример графика занятости, список дополнительных услуг и добавление отзыва на страницу. Сайт намеренно простой; заказ, бронирование и modal отложены по указанию пользователя.

## Как объяснить проект за минуту

Это статический многостраничный сайт на HTML, Bootstrap 5.3.8 и небольшом собственном CSS. Bootstrap — единственный фреймворк. Его CSS формирует сетку и внешний вид компонентов, а JS Bundle управляет мобильным меню, вкладками номеров и FAQ. Собственный JavaScript закрывает меню после перехода, открывает вкладку выбранного номера и добавляет отзыв в DOM. Сервер и база данных не подключены.

Класс row создаёт строку, а col-12 col-md-6 col-lg-4 меняет ширину карточки с 100% на 50% и затем примерно на 33,3%. Поэтому адаптивность получается из готовых media queries Bootstrap, а не из сложного JavaScript.

Меню и FAQ используют data-bs-toggle и data-bs-target: библиотека по нажатию находит связанный блок по id и переключает его состояние. Наш обработчик отзыва вызывает preventDefault, создаёт HTML-элементы через createElement, вставляет пользовательский текст через textContent и добавляет карточку в reviewList.
