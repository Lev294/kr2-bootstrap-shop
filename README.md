# Лапки — агрегатор передержек для животных

Контрольная работа №2: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

Автор: Демидовс Лев Алексейсович, группа ЭФБО-05-25.

Отдельная реализация онлайн-сервиса для поиска передержек кошкам, собакам, кроликам и морским свинкам. «Лапки» — агрегатор: собственной гостиницы и физического места приёма животных нет. Размещение и уход обеспечивают исполнители из каталога. Проект КР №1 не изменяется.

## Текущий объём работы

По последнему указанию пользователя всё, связанное с заказом, отложено: нет страницы заявки, бронирования, выбора дат и модальных окон. Это намеренное отступление от требований к форме и modal в практиках №10–11. Нельзя считать эти пункты выполненными.

Готова информационная часть: описание сервиса, предложения передержек и цены, условия исполнителей, справочная доступность, дополнительные услуги, отзывы о сервисе и FAQ. В интерфейсе нет учебных подписей и имени автора; учебная информация остаётся только в документации репозитория.

## Практическая работа №9

Главная страница построена на Bootstrap-сетке: шапка, navbar, hero, преимущества, популярные номера и подвал.

Используются `container`, `container-fluid`, `row`, `col-12`, `col-md-6`, `col-lg-4`, `g-4` и utility-классы. На мобильном экране карточки идут по одной, от 768 px — по две, от 992 px — по три.

В первом коммите использована версия Bootstrap 5.3.3 из примера №9. Начиная с №10 на всех страницах одинаковая версия 5.3.8 из методичек №10–11.

## Практическая работа №10

Созданы страницы каталога и условий проживания. Навигация одинакова на всех страницах; текущий пункт выделен `active` и `aria-current="page"`.

Компоненты:
- `navbar`, `collapse` — адаптивное меню;
- `breadcrumb` — хлебные крошки над содержимым внутренних страниц: ссылки на родительские разделы и текущая страница с aria-current;
- `card` — номера и услуги;
- `btn` — ссылки с оформлением кнопок;
- `badge` — вид питомца и статус занятости;
- `alert` — информационные сообщения;
- `accordion` — FAQ;
- `nav-pills`, `tab-pane` — вкладки предложений передержек по видам питомцев;
- `table`, `table-responsive` — тарифы и график;
- `form-control` — поля отдельного отзыва на главной странице.

Форма отзыва не связана с заказом. Отзыв появляется только на открытой странице и исчезает после обновления. Введённый текст вставляется через `textContent`, поэтому браузер не исполняет его как HTML.

## Практическая работа №11

Проверяются структура, подключение Bootstrap, навигация, сетка, компоненты и README. Страница заявки и modal отложены по указанию пользователя.

Локальное подключение Bootstrap — необязательное дополнительное задание методички; в этой простой версии оставлен CDN.

## Как устроен код

- HTML хранит содержимое страниц и классы Bootstrap.
- Bootstrap CSS задаёт сетку и оформление компонентов.
- Bootstrap JS Bundle управляет меню, вкладками и FAQ через `data-bs-toggle` и `data-bs-target`.
- `css/custom.css` добавляет фоны, размер изображений, зелёные акценты вкладок, отступ для якорей и перенос текста отзыва.
- `js/main.js` закрывает мобильное меню после перехода, выбирает вкладку предложения по ссылке и добавляет отзыв на страницу.

Навбар закреплён классом `sticky-top`: после прокрутки шапки он остаётся у верхней границы окна, сохраняя место в потоке документа. Это позволяет обойтись без фиксированного отступа для всей страницы. `scroll-margin-top` не даёт меню закрывать заголовки при переходе по якорям.

Карточки ведут на `product.html?place=cat`, `?place=dog` и `?place=small`. Код читает параметр через `URLSearchParams` и открывает соответствующую вкладку методом Bootstrap `Tab.show()`. Для совместимости сохранены старый параметр `room` и якоря `#cat`, `#dog`, `#small`. Без параметра открывается предложение для кошек; другие варианты доступны рядом.

React, Vue, npm, сборщик, сервер и база данных не используются.

## Подключение Bootstrap

На всех четырёх страницах:
```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css">
<link rel="stylesheet" href="css/custom.css">
```

Перед закрытием `body`:
```html
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/js/bootstrap.bundle.min.js"></script>
<script src="js/main.js"></script>
```

`custom.css` подключён после библиотеки: при равной специфичности и остальных равных условиях его более поздние правила получают приоритет. Bundle содержит JavaScript-компоненты Bootstrap и Popper; jQuery не нужен.

## Запуск и проверка

Из папки проекта запустите `python3 -m http.server 8000` и откройте `http://localhost:8000`. HTTP нужен для корректной загрузки внешнего SVG-спрайта в браузерах, ограничивающих такие обращения через `file://`. Для Bootstrap из CDN нужен интернет.

Проверьте:
1. Переходы между четырьмя страницами и одинаковый порядок ссылок в navbar и подвале.
2. Раскрытие меню на мобильном экране.
3. Перестроение колонок при изменении ширины окна.
4. Раскрытие FAQ на странице условий.
5. Добавление отзыва на главной.
6. Отсутствие горизонтальной прокрутки всей страницы; таблицы могут прокручиваться внутри своего контейнера.
7. Закрепление навбара после прокрутки и переход на отдельную страницу «О нас и контакты» на мобильном экране.
8. Открытие соответствующего номера из каждой карточки, а не всегда номера для кошек.

Главная дополнена тремя разделами: шаги выбора передержки, вопросы исполнителю и памятка по подготовке питомца. При окне 1440 × 900 px её высота составляет 3501 px — около 3,9 высоты окна; новая страница «О нас и контакты» занимает 2637 px — около 2,9. Точное число экранов зависит от высоты окна; на телефоне колонки складываются и страница становится длиннее. Минимальная высота секций для растягивания страницы не задаётся.

График на 16–22 ноября 2026 года и цены — демонстрационные данные предложений, не подтверждённые сведения реальных исполнителей.

## Контакты поддержки сервиса

Сервис работает онлайн. По указанию пользователя физический адрес удалён из интерфейса и описания проекта. В контактах оставлены:

- телефон: +7 (906) 555-12-34 — сохранён из локальной правки пользователя;
- время работы поддержки: ежедневно, 09:00–20:00;
- почта: hello@lapki.example (домен .example предназначен для примеров).

Данные используются в макете; работоспособность телефона не проверялась. Контакты и сведения о сервисе объединены на отдельной странице `about.html`. Контакты повторены в подвале всех четырёх страниц в порядке «телефон → время → почта» с маленькими векторными иконками.

Telegram и VK добавлены как кликабельные ссылки-заглушки с иконками. Обработчик в main.js отменяет переход через event.preventDefault(), поэтому нажатие не меняет адрес и не прокручивает страницу. Для настоящих ссылок нужно заменить href и удалить data-placeholder.

## Общие элементы интерфейса

В navbar и подвале одинаковый порядок: «Главная → Передержки и цены → Условия проживания → О нас и контакты». Вместо двух якорных пунктов используется один переход на `about.html`. Подвал содержит отдельный элемент `nav` с собственным `aria-label`; текущая страница отмечена `aria-current`.

Оба логотипа используют один векторный файл `images/logo.svg` и одинаковые размеры 150 × 40 px. Иконки телефона, времени, почты и соцсетей собраны в `images/icons.svg`: элемент `use` выбирает нужный `symbol` по id. Цвет наследуется через `currentColor`, поэтому в контактах он зелёный, а в тёмном подвале — золотистый. Декоративные иконки скрыты от скринридеров атрибутом `aria-hidden`, рядом остаются текстовые подписи.

Стрелка рядом с «Наверх» удалена; оставлена обычная ссылка-кнопка. Адресов гостиницы или офиса сервиса нет. Новые зависимости не потребовались.
