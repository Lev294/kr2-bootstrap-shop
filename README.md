# Лапки — гостиница для домашних животных

Контрольная работа №2: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

Отдельная реализация сайта гостиницы для животных. Проект КР №1 не изменяется.

## Практическая работа №9

Созданы главная страница, шапка, navbar, hero-блок, преимущества, сетка номеров и подвал.
Используются `container`, `container-fluid`, `row`, `col-12`, `col-md-6`, `col-lg-4`, `g-4` и utility-классы.
Bootstrap 5.3.3 CSS и JS Bundle подключены через CDN; `css/custom.css` подключён после Bootstrap.

## Структура

- `index.html` — главная страница.
- `css/custom.css` — небольшие изменения оформления.
- `images/` — собственные SVG-иллюстрации номеров.
- `README.md` — описание работы.

## Запуск

Открыть `index.html` в браузере. Для CDN-подключения нужен интернет.
Сборщик, npm, React и Vue не используются.
